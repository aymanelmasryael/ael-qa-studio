# Changelog

All notable changes to AEL QA Studio will be documented in this file.

## [1.0.0] — 2026-07-10

### Added

- Dashboard with statistics overview and recent activity tracking
- 13 quality assurance categories with icons and descriptions
- Review prompts with expand/collapse, copy to clipboard, and export
- Interactive checklists with real-time progress tracking
- Enforceable standards with severity badges (error, warning, info)
- Knowledge base entries with tag filtering
- Code examples with syntax highlighting and copy
- Curated reference links per category
- Full-text search across prompts and knowledge base
- Markdown report export from templates
- Light/dark theme toggle with localStorage persistence
- Deep linking via URL hash for categories and search
- Responsive design (mobile, tablet, desktop)
- Keyboard accessibility and screen reader support
- Print stylesheet
- Reduced motion support

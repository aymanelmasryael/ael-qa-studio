# Roadmap

## v1.1 (Next)

- Custom prompt creation and editing
- Checklist completion persistence (localStorage)
- Drag-and-drop checklist reordering
- Report history and saved exports
- Keyboard shortcuts (Ctrl+K for search, Ctrl+E for export)

## v1.2

- User-defined categories and custom data files
- Team sharing via URL export/import
- PDF export of reports and checklists
- i18n / multi-language support

## v1.3

- Plugin system for custom data sources
- Integration with GitHub Issues for action items
- API mode for CI pipeline integration
- Automated audit scheduling

## Future

- AI-assisted prompt generation and review
- Real-time collaborative checklists
- VS Code extension for in-editor QA reviews
- Mobile native apps (SwiftUI)
